# Pedestrians — model reference pack

Docs for a future model-harness pass. The city keeps one instanced mesh named `crowd`. This pack does not change that mesh, the walk shader, or the district shares.

Read in this order:

1. [look-target.md](look-target.md) — silhouette, proportions, pose set, coats and umbrellas, materials, how a person reads at 5 / 30 / 200 m.
2. [scale.md](scale.md) — metres, the boxes that ship today, district shares.
3. [lod.md](lod.md) — Ultra / High full, Medium lighter, Low simple.
4. [references.md](references.md) — film notes and street photos by URL. Do not download them into git.
5. [harness-plan.md](harness-plan.md) — rounds, critic rubric, silhouette-overlap views.
6. [silhouette.svg](silhouette.svg) — overlap plates (`#stand`, `#short`, `#rain`, `#side`).

The one-page summary is [../dancer-crowd-refs.html](../dancer-crowd-refs.html).

Original people. No faces, no likenesses, no brands on the clothes.
