# Reference board (local only)

Photographs dropped in this folder are not committed. Use public-domain or Creative Commons pictures of real brutalist and megastructure buildings. Do not download Blade Runner frames, logos, or likenesses.

Suggested Commons subjects, searched by name at capture time:

- Barbican Estate, London
- Boston City Hall
- Habitat 67, Montreal
- Trellick Tower, London
- Geisel Library, San Diego

The scored silhouettes are original diagrams in `tools/building-harness/audit.mjs` (`envelope`), not tracings of those photos.
